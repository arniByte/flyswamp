# Flyswamp: о проекте

## Что это

Научная симуляция в форме игры. Плодовая мушка *Drosophila melanogaster* живёт в 3D-болоте: ищет по запаху гнилые фрукты, попадает в росянки, которые пахнут почти как еда, уворачивается от лягушек и учится на своём опыте. Мозг мухи — не придуманная нейросеть, а реальная схема связей нейронов (коннектом) из открытого датасета **MaleCNS v1.0**: полная нервная система самца, мозг и брюшной нервный тяж, 2026 год. Режим «рентген» показывает, какие из реальных нейронов работают в данный момент.

## Зачем

1. **Честно проверить, что можно вывести из коннектома.** В сети много проектов вида «натренировали муху играть или торговать». Обычно непонятно, где кончается биология и начинается подгонка. Здесь у каждой части есть статус (данные / опубликованный метод / проверено / дизайн / заглушка), и каждая фаза закрывается численной проверкой против опубликованного результата. Реестр — [SCIENCE.md](SCIENCE.md).
2. **Научная игра.** Игрок ставит на мухе эксперименты, как в лаборатории: оптогенетическая активация, обусловливание запахом, контроли. Он видит, какие нейроны отвечают, и понимает, что из этого вывод модели, а что допущение.
3. **Испытательный стенд.** Воспроизводимые бенчмарки: наш движок против эталонной модели на Brian2, модель на FlyWire против MaleCNS. Каждое число в документах можно пересчитать скриптом из `validation/`.

## Из чего состоит

```
 открытые данные ─► pipeline/ (Python) ─► web/public/data, .cache/graphs
                                              │
 опубликованные модели ─► web/src/sim/ (движок LIF, модель MB, мир болота)
                                              │
                          web/src/render/ + ui/ (three.js: муха, рентген мозга, болото, HUD)

 validation/ — сверка движка и моделей с эталонами и литературой
```

| Слой | Что делает | Где |
|---|---|---|
| Пайплайн данных | качает MaleCNS, собирает цепь грибовидного тела, граф всего CNS, меши нейропилей, скелеты нейронов, тело мухи | `pipeline/` |
| Спайковый движок | leaky integrate-and-fire по Shiu et al. 2024, сверен с их кодом | `web/src/sim/lif.js`, `graph.js` |
| Модель обучения (прототип) | rate-модель грибовидного тела с дофаминовой пластичностью | `web/src/sim/brain.js` |
| Мир | болото, шлейфы запаха, фрукты, росянки, лягушки, «гонка вооружений» | `web/src/sim/world.js`, `odors.js` |
| Графика и интерфейс | 3D-муха с рентгеном, нейроны и нейропили, болото, HUD | `web/src/render/`, `web/src/ui/` |
| Проверка | эталоны, сравнения, бенчмарки | `validation/`, `web/test/` |
| Утилиты | headless-эксперименты, скриншоты, упаковка в артефакт, восстановление окружения | `scripts/` |

## Инструменты

- **Браузер:** three.js (3D), Vite (сборка), чистый JavaScript без фреймворков. Бэкенда нет, всё считается у пользователя.
- **Python-пайплайн:**
  - numpy, pandas, pyarrow — таблицы коннектома;
  - tensorstore — объёмы нейропилей;
  - scikit-image и trimesh — меши;
  - fast-simplification — упрощение мешей;
  - mujoco — чтение модели flybody.
- **Проверка:** Brian2 — симулятор, на котором написана модель Shiu; служит только эталоном. Node test runner — тесты, Playwright — скриншоты.
- **Дальше по плану:** MuJoCo WASM для физики тела, WASM SIMD или WebGPU для скорости.

## Что наше, а что взято готовым

Архитектура и весь код — наши. Готовыми взяты данные, одна 3D-модель и библиотеки:

| Взято готовым | Что мы с этим делаем |
|---|---|
| данные коннектома и анатомии | фильтруем, собираем цепи и графы, строим меши из объёмов, упрощаем скелеты |
| 3D-модель тела мухи (flybody) | конвертируем в glTF, собираем риг из 102 суставов, анимируем крылья, ноги и хоботок, делаем шейдер рентгена |
| модель Shiu et al. 2024 (Python/Brian2) | переписали на JavaScript по уравнениям и сверили численно; их код не копировали |
| three.js, Vite, Python-библиотеки | используем как инструменты |

Своё:
- **Пайплайны данных:** цепь грибовидного тела, граф всего CNS, анатомия, тело.
- **Спайковый движок** с тестами. При сверке нашлась тонкость Brian2 с рефрактерным периодом.
- **Методы переноса:**
  - восстановление правила знаков нейромедиаторов из графа Shiu;
  - сопоставление нейронов между версиями FlyWire;
  - перенос экспериментов с FlyWire на MaleCNS по профилю связей;
  - бенчмарк затухания;
  - оценка масштаба синапсов между датасетами.
- **Прототип обучения и мир болота** с росянками, лягушками и гонкой вооружений.
- **Вся графика:** болото, растения, лягушка, шлейфы, нейроны в рентгене, HUD. Готовых 3D-ассетов, кроме тела мухи, нет.

## Где мы сейчас

| Фаза | Статус |
|---|---|
| P0 — реестр происхождения | готово |
| P1 — движок совпадает с эталоном Shiu (0 отличающихся нейронов на 100, 150, 200 Hz) | готово |
| P2 — модель Shiu на целом MaleCNS | в работе. Вкусовая часть гейта пройдена: `w_syn` 0,20, отложенные сиды, перемешанная проводка проваливает тест. Осталось: KC (Turner 2008) и looming (von Reyn 2014) |
| P3 — настоящие запахи (DoOR) | не начато |
| P4 — обучение на спайковом движке | не начато |
| P5 — замкнутый контур: мир → мозг → тело | не начато |
| P6 — графика, интерфейс, механики | после P2–P5 |

Целый MaleCNS (165 122 нейрона) крутится в игре спайковой моделью в Web Worker, рентген показывает его спайки. Из мира в него пока идёт только вкус. Поведение и обучение считает прототипная rate-модель — это каркас до P4–P5.

## Как запустить

```bash
cd web && npm install && npm run dev      # игра, http://localhost:5173
cd web && npm test                        # тесты движка, модели и мира
scripts/setup.sh                          # эталоны, Brian2, данные MaleCNS (~1,1 ГБ), графы для validation/ и pipeline/, граф CNS для игры
```
